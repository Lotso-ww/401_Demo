401 Demo
========

Run 401_demo.exe to start the application.

This directory must remain intact. The DLL files, plugins directory, and the
Drivers directory are runtime dependencies and must stay beside 401_demo.exe.

The application creates its database and captured images in the current user's
Windows application-data directory on first run. No test database or captured
images are included in this release package.

For hardware use, the operating system must have the matching IDS camera and
RFID reader drivers installed. Qt, Visual Studio, CMake, and the development
SDKs are not required to run this release.
